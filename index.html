Overall Page Structure (CSS Grid) The primary layout is created using CSS Grid on `.dashboard-container`. It uses named grid areas (`header`, `sidebar`, `main`) to explicitly define component placements: - **Header:** Spans full width across the top (`64px` height). - **Sidebar:** Fixed width column (`240px`). - **Main Area:** Takes up remaining space (`1fr`). ### 2. Internal Component Layout (Flexbox) Flexbox is utilized inside components to handle alignment and direction: - **Header:** Uses `display: flex` with `justify-content: space-between` to separate the logo and user profile. - **Sidebar Navigation:** Uses `flex-direction: column` for vertical stacking on desktop, switching to `flex-direction: row` for horizontal scrolling on smaller viewports. - **Dashboard Cards:** Uses Flexbox internally to organize icon/title headers and content rows. ### 3. Theme System (CSS Variables) Color tokens are declared on the `:root` pseudo-class: - `--brand-color`: Primary blue accent used for interactive highlights and branding. - `--accent-color`: Supporting brand element color. - `--bg-color` & `--surface-color`: Background layers establishing visual hierarchy. - `--primary-text` & `--secondary-text`: High and medium contrast text colors. ### 4. Responsiveness A `@media (max-width: 768px)` media query collapses the grid into a single-column layout: - Switches `.dashboard-container` grid-template-areas to single vertical stacking. - Converts navigation menu from vertical list to horizontal scroll bar. ### 5. Micro-interactions Card hover and focus states feature a micro-interaction: - `transform: translateY(-4px)` elevates the element smoothly. - CSS `transition` configured to **200ms** (below the 250ms threshold). - Applies equally to keyboard navigation (`:focus-visible`) and mouse hover (`:hover`). ### 6. Dark Theme (Stretch Goal) Implemented via `@media (prefers-color-scheme: dark)` which dynamically redefines the `:root` variables to support system-level dark mode preferences without extra JavaScript.
